 🌊 OceanGuard – Marine Awareness & Volunteer Tracking Website

📌 Project Overview

OceanGuard is a web-based marine awareness and volunteer tracking platform developed using HTML, CSS, and JavaScript.

The project aims to spread awareness about ocean pollution, educate visitors about marine environmental challenges, and encourage people to participate in ocean conservation activities.

It provides educational resources, volunteer registration, activity logging, and a fundraiser progress interface through a simple and interactive website.

✨ Key Features

 1. Marine Awareness
- Information about plastic pollution.
- Educational content about coral bleaching.
- Awareness of oil spills and their environmental impact.
- Information about overfishing and marine ecosystem protection.

2. Volunteer Registration
- Registration form for volunteers.
- Collects name, email, location, and interests.
- Displays registered volunteer details.

3. Volunteer Action Log
- Log environmental activities.
- Supports beach cleanups, plastic reduction, awareness posts, and community events.
- Calculates volunteer points based on time spent.

4. Ocean Facts & Dashboard
- Displays ocean pollution statistics.
- Automatically changes environmental facts.
- Provides an interactive facts section.

5. Fundraiser Section
- Donation entry interface.
- Displays donation details.
- Shows fundraising progress toward a target.

6. Interactive Help Widget
- Provides quick guidance about registration, activities, donations, and educational resources.

⚙️ Installation & Execution

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in Visual Studio Code.

3. Install the Live Server extension (if required).

4. Open `main.html`.

5. Right-click and select **Open with Live Server**.

6. Explore the OceanGuard website in your browser.
